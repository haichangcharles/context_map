# Contributing to Contextify

Thanks for contributing to Contextify.

## Development Setup

```bash
npm install
cp .env.example .env.local
npm run dev
```

## Before Opening a PR

- Keep changes focused and easy to review.
- Run checks locally:

```bash
npm run lint
npm run test:mainline
```

- Update docs if behavior or configuration changes.

## Pull Request Guidelines

- Use a clear title and describe the motivation.
- Explain how to test your change.
- Include screenshots/GIFs for UI changes when possible.

## Scope

Good first contributions:

- bug fixes
- docs improvements
- test coverage improvements
- small UX refinements
